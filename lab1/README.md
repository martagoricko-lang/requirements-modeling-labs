# Онлайн-магазин (E-Commerce Platform)

## Опис домену
Концептуальна модель даних для платформи електронної комерції. Система підтримує каталог товарів з варіаціями (розмір, колір), категоризацію товарів, управління замовленнями, позиціями замовлень та проведенням оплати.

## Мета проєкту
Розробка концептуальної ER-моделі даних (Entity-Relationship) для забезпечення цілісності та нормалізації (3NF) структури даних електронного магазину.
