# Предметна область: Система управління онлайн-магазином (E-Commerce)

## Бізнес-вимоги до моделі даних

- **Каталог та категорії:** Підтримка багатоуровневої структури товарів із можливістю віднесення товару до відповідної категорії.
- **Управління варіаціями (SKU):** Можливість обліку різних варіацій одного товару (за розмірами, кольорами) із роздільним контролем залишків на складі.
- **Обробка замовлень:** Реєстрація замовлень покупців із фіксацією дати створення та поточного життєвого циклу (статусу).
- **Збереження цінової історії:** Обов'язкова фіксація ціни кожної одиниці товару на момент оформлення замовлення для захисту від подальших змін цін у каталозі.
- **Гнучка оплата:** Підтримка різних сценаріїв розрахунку, де факт оплати може відбуватися як під час створення замовлення, так і після його підтвердження.
